C2RustXW-CLI 是一个开源命令行工具，旨在帮助开发者将 C 语言项目逐步、安全地迁移到 Rust。与一次性全量翻译不同，C2RustXW-CLI 采用函数粒度的渐进式迁移策略：逐个翻译 C 函数为 Rust 代码，并在每次翻译后立即利用原始 C 项目的构建系统（基于 CMake）进行集成编译验证。若编译失败，工具会暂停并提示开发者介入修正生成的 Rust 代码，确保每一步迁移都保持项目可构建、功能一致。
该工具特别适用于大型遗留 C 项目，允许团队以可控、低风险的方式逐步引入 Rust，同时保留原有 C 代码的其余部分不变，实现混合编译与运行。

# 核心设计理念
- 渐进迁移（Incremental Migration）：一次只迁移一个函数，降低复杂度和风险。
- 构建驱动验证（Build-Driven Verification）：依赖原项目 CMake 构建系统自动验证翻译结果的正确性。
- 人机协同（Human-in-the-Loop）：当自动生成的 Rust 代码无法通过编译时，交由开发者手动修复，再继续流程。
- 零侵入性（Non-Intrusive）：不修改原始 C 代码，仅生成对应的 Rust 替代实现并通过 FFI 集成。

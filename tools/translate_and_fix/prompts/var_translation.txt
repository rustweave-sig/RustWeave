**数据类型映射：**

- 保持与C代码中完全相同的名称，特别注意大小写，类型、变量、函数都必须一一对应。

- 如果C变量定义没有标明它是一个常量（没有`const`关键字），那么翻译结果必须添加`mut`关键字。
- 如果C变量定义标明它是一个常量（有`const`关键字），那么翻译结果也必须添加`const`关键字。

**变量初始化：**
- 如果C变量有初始化值，则翻译结果必须使用完全相同的初始化值

- C 全局命名空间的静态变量 → Rust 保持与C完全相同的定义。

**指针处理：**
- C 函数指针类型 → Rust `Option`包装的函数指针。

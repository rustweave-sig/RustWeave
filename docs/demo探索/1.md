## `c/Makefile`
此处Makfile有一个点，我写到`问题`里

```makefile
calc: main.c
	gcc -fPIC -rdynamic \
	    -Wl,--unresolved-symbols=ignore-in-object-files \
	    main.c -o calc

clean:
	rm -f calc
```

```bash
cd c
make clean
make
nm -C calc | grep add
#该符号非强定义（这里可以忽略这个操作，或许交给用户来做？确保已经成功注释了该函数
			U add
```

## `rust/Cargo.toml`中添加 crate-type = ["cdylib"]

```toml
[package]
name = "rust_add"
version = "0.1.0"
edition = "2021"

[lib]
crate-type = ["cdylib"]
```
每转译一个函数就追加到lib.rs里面

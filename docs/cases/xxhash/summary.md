## benchMem 的当前定位

- `benchMem` 已是当前共享闭包扩展中的真实主阻塞。
- 它不是单一报错，而是至少两层问题叠加：

  2. `static mut` 数组与 raw pointer 的 stable Rust lowering 不稳定
- 已观察到的典型错误族包括：
  - `E0061`
  - `static_mut_refs`
  - `E0658 array_ptr_get`
  - `E0599 raw pointer .len()`

  - `hybrid-pass`
